Where do I get the token?

GitHub → your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Choose "Only select repositories" and pick your parking repository. Under Repository permissions set Contents and Actions to "Read and write". Generate it and paste it above. The token is stored only in this browser, on this device.
